# My Sadenverse — checklist personal

Una pequeña PWA en español, pensada para iPhone. Incluye checklist por saga, estados Pendiente/Leyendo/Leído, buscador, estadísticas y exportar/importar progreso.

## Publicarla gratis con GitHub Pages
1. Descomprime `my-sadenverse-pwa.zip`.
2. Crea un repositorio en GitHub (por ejemplo `my-sadenverse`) y sube `index.html`, `manifest.webmanifest`, `icon.svg` y `sw.js` a la raíz.
3. En el repositorio, entra en **Settings → Pages**.
4. En “Build and deployment”, elige **Deploy from a branch**, branch `main`, folder `/ (root)`, y guarda.
5. Espera a que GitHub Pages muestre la URL HTTPS publicada.
6. En el iPhone, abre esa URL en **Safari** → botón **Compartir** → **Añadir a pantalla de inicio**.

## Guardado
- El progreso se guarda en el almacenamiento local de ese navegador/dispositivo.
- Usa **Exportar progreso** para guardar una copia JSON y **Importar progreso** para restaurarla en otro navegador.
- Si borras los datos de Safari, puedes perder el progreso local; exporta una copia periódicamente.
- Esta versión no sincroniza automáticamente entre dispositivos ni tiene inicio de sesión.
